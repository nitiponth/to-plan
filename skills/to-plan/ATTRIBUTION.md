# Attribution

The to-plan instructions and paired-document template are a new adaptation of
planning ideas from the pinned sources in sources.json:

- Matt Pocock's to-spec: observable requirements, scope, decisions and testing seams.
- Matt Pocock's to-tickets: verifiable deliverables and real blocking dependencies.
- Jesse Vincent's Superpowers writing-plans: concrete paths, shared contracts,
  test assertions, commands and implementation handoff.

The original Matt Pocock and Superpowers MIT notices are preserved in LICENSES.txt.
This skill does not execute or bundle those source skills. Their tracker publishing,
executor selection and automatic implementation behavior are not adopted.

Anthropic's skill-creator was used to develop and evaluate the skill. Its tools remain
in the development workspace and are not part of this skill package. The paired
evaluations use Codex agents, not Claude, and test plans/handoffs rather than code.
The original evaluator license and pinned tool sources are retained with development
evidence. Matt's implement, tdd and code-review are required only in the receiving
implementation session; no change to those skills is included.
